# U3-ejercicio21
### Sistema de Empleados y Tipos de Contratación

**Objetivo principal:** Desarrollar una jerarquía de clases en Java que permita representar empleados con diferentes modalidades de contratación y calcular sus remuneraciones de manera especializada.

Se implementa la clase base `Empleado` y dos clases derivadas (`EmpleadoAsalariado` y `EmpleadoPorHora`), cada una con sus propios atributos y reglas de cálculo salarial.

El ejercicio aplica **herencia, encapsulamiento, constructores, sobrescritura de métodos y reutilización de código**, permitiendo representar distintos tipos de empleados mediante una estructura común.
